# Escala Técnica

Página única em HTML/CSS/JS puro (sem build, sem dependências) para montar a escala semanal de técnicos por cidade.

- Abrir `index.html` direto no navegador.
- Dados salvos no `localStorage` do navegador — cada computador mantém sua própria cópia.
- Edite os arrays `CIDADES` e `FERIADOS` no topo do `<script>` para ajustar cidades atendidas e feriados.
